# Leitura de Vídeo

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status-Concluído](https://img.shields.io/badge/Status-Concluído-brightgreen?style=for-the-badge&logoColor=white)

Leitura de vídeo por meio da biblioteca OpenCV e aprendendo sobre medidas usadas para configurá-lo.

---
## 📚 Aprendizados
- Classe VideoCapture (OpenCV)
- Método IsOpened
- Propriedades dos vídeos
- Método Get() da classe VideoCapture()

## ⚙️ Funcionalidades
- Ao executar o arquivo, podemos ver no terminal a altura, a largura e os quadros por segundo do vídeo

## 🛠️ Stack
- Python
- OpenCV

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/BiaHashi/Read_Video
```

2. Abra o arquivo ".py" e execute-o no VS Code.
